# Notice

This repository is a curated bundle of security-related Codex skills assembled from:

- original custom skills
- locally adapted skills
- skills derived from third-party open-source materials

## Important publishing notes

1. Do not assume a single repository-wide license automatically applies to every skill folder.
2. Some skills may include their own `LICENSE.txt` or attribution requirements.
3. Skills adapted from Trail of Bits content should retain clear source attribution and should be reviewed against the upstream license terms before public distribution.
4. Before making the repository public, review each skill for:
   - organization-specific internal workflows
   - private infrastructure names or file paths
   - customer names or internal project references
   - sensitive testing guidance that should remain private

If you want a public release, it is safer to do a final per-folder license and content review first.
